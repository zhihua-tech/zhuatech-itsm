# ITSM API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 身份认证 |
| GET | `/api/admin/dashboard` | 服务运营指标 |
| GET | `/api/admin/work-orders` | 服务工单队列 |
| GET | `/api/shopfloor/dashboard` | 工程师工作台 |
| POST | `/api/shopfloor/work-orders/{id}/reports` | 更新工单工作日志 |
| POST | `/api/admin/change-risk` | 评估 IT 变更风险和审批路径 |
