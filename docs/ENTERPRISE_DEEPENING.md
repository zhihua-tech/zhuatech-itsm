# ITSM 企业服务治理闭环

本项目由上海如静知华信息科技有限公司维护，技术与深度定制请访问 [知华科技官网](https://www.zhuatech.cn/)。

本轮围绕 ITIL 常用主线补齐配置项、事件、问题与变更：配置项启用后方可关联业务；事件根据 P1—P4 自动计算响应期限并识别重大事件；事件必须完成分派、解决、关闭的顺序流转；已解决事件可沉淀根因、已知错误和规避方案。

变更根据影响度、概率和紧急类型形成风险分，提交 CAB 前必须具备回退方案。只有 CAB 批准的变更可以实施，实施需要证据摘要，完成后才能关闭。核心动作写入审计事件，管理操作要求 ADMIN 权限。

自动化验收覆盖事件—问题—变更完整闭环、未分派事件禁止解决、无回退方案禁止提交。生产使用前还需按实际组织接入监控平台、CMDB 发现、通知渠道、值班体系和高可用部署。
